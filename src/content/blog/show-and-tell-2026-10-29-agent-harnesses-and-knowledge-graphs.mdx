Fourteen builders took the podium at Malaysian AI's Weekly Show & Tell in Kuala Lumpur on 29 October 2026. Rather than generic prompt wrappers, most demos focused on the plumbing around models: custom agent harnesses, multi-model routing, context pruning, hybrid retrieval, and local-first software.

## Agent Harnesses, Multi-Model Routing, and Context Pruning

Several engineers walked through how they control token spend, quota limits, and reasoning reliability when running agents all day.

**Andrew** shared custom modifications he made to the Antigravity AI coding harness. Noticing that Gemini API keys worked in the Antigravity CLI but not the desktop GUI, he prompted the agent to patch its own interface. His setup adds direct Gemini API key support, a live tokens-per-second counter, and automated failover across multiple imported Google accounts when quotas expire. Pairing this with a custom ROI analytics dashboard, he tracked roughly 5 billion tokens consumed in a single month across five Google AI Pro accounts on Gemini Flash, using bundled subscription quotas for general work while reserving Claude and Codex for coding.

**Rasan Chandra** broke down the multi-model harness architecture behind Orvaly, a meeting intelligence platform. Instead of relying on one monolithic prompt, Orvaly wraps each LLM call in a dedicated harness with scoped tools and Cloudflare vault memory. Its live execution agent, Astro, monitors transcripts to propose and decompose tasks for user approval. To keep costs down to a few pennies per meeting, lightweight decision models inspect transcripts and screen feeds, escalating to Claude Sonnet or Opus only when complex reasoning is needed. For long sessions (up to eight hours), a five-pass post-meeting synthesis pipeline avoids middle-of-transcript compression loss.

**Faris Irfan** demonstrated managing full-stack client builds (including a food delivery app, a navigation tool, and the Kolkay beta onboarding platform) directly from his mobile phone via screen mirroring into Claude Code. To protect his $100 Claude budget, he routes critical architecture to Claude Opus and delegates routine scaffolding and simple pages to Codex, Grok, and ChatGPT. For front-end work, he pairs Taste Skill with explicit color palettes and design standards, repurposes Deck Gallery slide layouts for app UI, and applies No AI Slop to clean up generated copy.

**Mohtasham Murshid Madani** tackled context bloat and redundant tool calls with Hlab (Harness Lab) and VideoClaw. His framework records individual agent runs into isolated templates, then generates variants inside CI pipelines that systematically prune server context and always-on skills. Optimization only starts after a task reaches 100% baseline accuracy, and if pruning causes accuracy to slip (for example to 90%), instructions are automatically re-injected so compacted variants double as regression tests.

## Knowledge Graphs, Sovereign Memory, and Vertical Data Harnesses

A second cluster of talks focused on turning messy personal notes, PDFs, and client spreadsheets into structured context that agents can reliably query.

**Aaron Liew** demoed AIOS, a personal context operating system organized into local folders inside Visual Studio Code and Obsidian, connected to Claude. A local librarian skill ingests PDFs (demonstrated with 'Zero to One') by extracting text and embedded diagrams directly into markdown. Rather than summarizing by raw page count, he calibrates extraction by factual density: roughly 5 atomic ideas for short books and 20 to 40 atoms for 500 to 1,000-page volumes, then links overlapping concepts across authors into molecular knowledge graphs.

**Ashvin Praveen** walked through Cleve, a cloud knowledge base and visual 'Brain' graph currently indexing about 1,700 of his own notes. When importing a 21,000-file codebase folder, Cleve automatically filters down to supported documentation formats (Markdown, HTML, Word, and PDF), pulling in 17 relevant files while preserving Obsidian backlinks. Under the hood, Cleve runs hybrid retrieval combining semantic vector search, grep keyword search, and graph traversal, followed by reranking with models like Cohere before passing context to parallel chat sessions.

**Brendan Beh** presented a specialized AI data harness for property development and construction cost estimation. Because client Excel bills of quantities arrive in messy formats, most engineering effort went into an automated AI cleaning pipeline. Once standardized into a vertical ontology, granular tagging paired with grep outperformed generic vector embeddings. To prevent math hallucinations on totals like RM 515,865.00 and RM 641,865.00, the agent runs deterministic arithmetic checks inside a code scratchpad, rejecting outputs that fail line-item reconciliation. Domain fine-tuning pushed benchmark accuracy to 100% on live industry ground truth, leaving upstream pre-tagging as the primary bottleneck.

## Practical Takeaways for Builders

- **Tier your models aggressively:** Use lightweight decision models, keyword heuristics, or secondary coding models for filtering and boilerplate, reserving Claude Opus or Sonnet for hard reasoning.
- **Do not default to plain vector search:** In structured verticals or large personal vaults, combining ontologies, grep, graph links, and rerankers beats raw embeddings.
- **Verify deterministically and prune in CI:** Arithmetic scratchpads (Brendan) and 100%-accuracy CI pruning loops (Mohtasham) catch silent regressions before users see them.
- **Design around real-world constraints:** Whether it is Mac mini memory wear, mobile battery and storage limits, or live demo screen-sharing hiccups, local constraints shape what actually holds up in daily use.
